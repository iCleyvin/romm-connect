RoMM Connect - Privacy Policy

Last updated: March 30, 2026

1. Overview

RoMM Connect ("the App") is a free, open-source mobile client for RoMM (ROM Manager) servers. This privacy policy explains how we handle your data.

2. Data We Collect

The App collects and stores the following data locally on your device only:

  • Server configuration: IP address and port of your RoMM server
  • Authentication tokens: OAuth2 access and refresh tokens for API communication
  • User credentials: Username and password stored locally for image authentication
  • Theme preference: Dark or light mode selection

3. Data We Do NOT Collect

  • We do not collect analytics or usage data
  • We do not use tracking pixels or third-party analytics SDKs
  • We do not collect device identifiers
  • We do not share any data with third parties
  • We do not serve advertisements

4. Server Communication

The App communicates exclusively with your self-hosted RoMM server. All data (ROMs, saves, states, metadata) is stored on your server, not on our systems. We have no access to your server or its data.

5. Third-Party Services

  • EmulatorJS (cdn.emulatorjs.org): The emulation engine is loaded from a public CDN. No user data is sent to this service.
  • IGDB (images.igdb.com): Game cover images may be loaded from IGDB's CDN. No user data is sent.
  • PayPal: If you choose to donate, you will be redirected to PayPal's website. We do not process payments directly.

6. Data Storage & Security

All user data is stored locally on your device using AsyncStorage. Authentication tokens are used to communicate with your RoMM server over your local network or VPN. We recommend using HTTPS for server connections when possible.

7. Data Deletion

You can delete all app data at any time by:

  • Using the "Sign Out" option in Settings (clears tokens and user data)
  • Using the "Change Server" option (clears all connection data)
  • Uninstalling the App (removes all locally stored data)

8. Children's Privacy

The App is not directed at children under 13. We do not knowingly collect data from children.

9. Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated date.

10. Open Source

RoMM Connect is open source. You can review the complete source code at github.com/iCleyvin/romm-connect.
